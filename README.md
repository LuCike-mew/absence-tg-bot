# MiraiBot — расписание и учёт пропусков для колледжа РКРИПТ

Telegram-бот, который автоматически берёт актуальное расписание занятий и замены
с сайта колледжа и позволяет студентам отмечать свои пропуски через встроенное
веб-приложение (Telegram Mini App).

## Возможности

- 📅 **Актуальное расписание** — бот сам скачивает `.xls` с сайта колледжа и
  парсит неделю для конкретной группы (например ВЕБ-42).
- 🔁 **Замены** — отдельно загружает PDF-файлы замен (по датам текущей недели) и
  показывает в расписании, кто и в какой аудитории ведёт пару вместо основного
  преподавателя.
- 🏫 **Аудитории** — у каждой пары отображается номер кабинета.
- ✍️ **Отметка пропусков** — через Mini App студент выбирает пары, на которых его
  не будет, и сохраняет их в личную историю.
- 🗂 **История пропусков** — хранится локально в SQLite (с автоматической очисткой
  устаревших записей).
- 🖥 **Настольная панель** — GUI-приложение для запуска/остановки бота, просмотра
  логов и автозапуска (сворачивание в системный трей).

## Как это работает

```
сайт колледжа ──► parser/schedule.py ──► расписание + замены
                        │                    │
                        ▼                    ▼
                 database/db.py ──► SQLite (пропуски)
                        │
                        ▼
            bot/handlers.py ──► Telegram (Mini App)
                        │
                        ▼
            absence-webapp (отдельный репозиторий)
```

- **Бот** работает через long polling (`aiogram`), поэтому не требует белого IP,
  домена или HTTPS — достаточно, чтобы компьютер был включён.
- **Веб-приложение** живёт в отдельном репозитории:
  [absence-webapp](https://github.com/LuCike-mew/absence-webapp)
  (размещено на GitHub Pages). Расписание и история передаются в него через
  сжатый gzip + base64 URL.

## Установка и запуск

### Требования

- Python 3.10+ (для разработки)
- Зависимости из `requirements.txt`

### Настройка

1. Склонируйте репозиторий и создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate      # Windows
   pip install -r requirements.txt
   ```

2. Создайте файл `.env` рядом с проектом (в репозитории его нет — он в
   `.gitignore`) и укажите токен бота, полученный у [@BotFather](https://t.me/BotFather):

   ```
   BOT_TOKEN=123456789:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
   ```

   Пример заполнения — в файле `.env.example`.

3. Запустите бота (в режиме разработки):

   ```bash
   python main.py
   ```

   Либо запустите графическую панель:

   ```bash
   python gui.py
   ```

## Сборка в исполняемый файл

Проект собирается в папку (onedir), чтобы все зависимости лежали рядом и не
возникало ошибок временного кеша, характерных для однопайловой сборки:

```bash
pyinstaller --noconfirm --clean MiraiBot.spec
```

Результат появится в `dist/MiraiBot/` — туда входят `MiraiBot.exe` и папка
`_internal/` с зависимостями. Рядом с `MiraiBot.exe` нужно положить файл `.env`
с токеном (как в разделе «Настройка»).

## Конфиденциальность данных

- Токен бота и прочие секреты не хранятся в исходном коде — только в локальном
  файле `.env`, который исключён из Git (`.gitignore`).
- История пропусков хранится локально в SQLite (`database/bot_data.db`) и
  автоматически очищается: удаляются записи старше 1-го числа предыдущего месяца.

## Технологии

- [aiogram 3.x](https://github.com/aiogram/aiogram) — Telegram Bot API
- [httpx](https://github.com/encode/httpx) — HTTP-запросы
- [xlrd](https://github.com/python-excel/xlrd) — чтение `.xls` расписания
- [pypdf](https://github.com/py-pdf/pypdf) — чтение PDF замен
- [aiosqlite](https://github.com/omnilib/aiosqlite) — SQLite
- [customtkinter](https://github.com/TomSchimansky/CustomTkinter) + [pystray](https://github.com/moses-palmer/pystray) — GUI и трей
